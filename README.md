# 🕊️ White Swan Holidays

Official website for **White Swan Holidays Pvt Ltd** — tailor-made international & domestic holidays, corporate travel, MICE, visa assistance, and flight booking from Ahmedabad.

🌐 **Live Website**: [https://whiteswanholidays.onrender.com/](https://whiteswanholidays.onrender.com/)

---

## 📸 Overview & Services

White Swan Holidays infuses life into holidays with bespoke itineraries and personalized travel management:

* 🌍 **International Holidays**: Curated packages for Dubai, Japan, Australia, Indonesia, Thailand, Europe, and more.
* 🇮🇳 **Domestic Holidays**: Handcrafted tours across Kashmir, Kerala, Himachal Pradesh, Gujarat (Kutch), Leh-Ladakh, and Sikkim.
* ✈️ **Visa & Air Ticketing**: Complete international visa guidance and domestic/international flight reservations.
* 💼 **MICE & Corporate Travel**: Corporate meetings, incentives, conferences, and exhibitions.
* 🏥 **Medical Tourism**: Specialized travel facilitation for global medical treatments in India.
* 🎁 **Corporate Gifting**: Curated corporate travel vouchers and gifting solutions.

---

## 🚀 Key Features

* **Instant WhatsApp Inquiry Builder**: Multi-step interactive planner on the home page that compiles holiday inquiries and opens directly in WhatsApp.
* **Modern & Responsive Design**: Custom CSS styling with smooth scrolling, mobile drawer navigation, and clean responsive layouts.
* **Fast Static Delivery**: Zero-dependency static architecture hosted on Render with automatic HTTPS and instant edge caching.

## 🛠️ Local Development

To run the website locally on your machine:

```bash
# Clone the repository
git clone https://github.com/Krishhtrivedi/whiteswanholidays.git

# Navigate into the project directory
cd whiteswanholidays

# Start a local web server (Python 3)
python3 -m http.server 8000
```

Then open `http://localhost:8000/` in your browser.

---

## 🌐 Deployment

The site is configured for zero-configuration continuous deployment on [Render](https://render.com/) using `render.yaml`. Every push to the `main` branch automatically deploys live to production.
